📖 关于 Model Router

Model Router — 成本感知的多模型路由框架。 核心特性： • 五级任务分类（vision / long / complex / medium / simple） • 免费优先 + 付费兜底回退链 • 零成本路由决策（关键词 + 长度启发式） • 支持视觉任务（图片/截图/OCR） • Python API / CLI / MCP / 桌面客户端 配置说明： • 编辑 config.json 添加或修改 provider • 每个路由级别定义候选链，免费在前付费在后 • 详细文档见 README.md 与 docs/DESIGN.md
